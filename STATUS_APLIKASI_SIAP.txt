   Pastikan MySQL di XAMPP Control Panel tetap HIJAU

═══════════════════════════════════════════════════════════
  ⚠️ JIKA MASIH ADA MASALAH
═══════════════════════════════════════════════════════════

1. Hard Refresh Browser
   Tekan: Ctrl + Shift + R

2. Clear Browser Cache
   Tekan: Ctrl + Shift + Delete
   Pilih: Cached images and files
   Klik: Clear data

3. Restart Server
   Di terminal, tekan: Ctrl + C
   Lalu ketik lagi: php artisan serve

4. Restart MySQL
   Di XAMPP Control Panel:
   - Stop MySQL
   - Tunggu 3 detik
   - Start MySQL lagi

5. Restart Komputer
   Jika semua gagal, restart komputer
   Lalu jalankan START.bat
